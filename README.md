# EDA-Titanic

## Exploratory Data Analysis of Titanic Dataset

This project performs Exploratory Data Analysis (EDA) on the Titanic dataset.

### Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

### Dataset
Titanic dataset containing passenger information such as:
- PassengerId
- Survived
- Pclass
- Name
- Sex
- Age
- SibSp
- Parch
- Fare
- Embarked

### Objective
To analyze the Titanic dataset and understand the factors that affected passenger survival.

### Notebook
The complete EDA is available in `Task_5_EDA_Titanic.ipynb`.
